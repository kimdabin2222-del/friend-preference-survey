# 친구 취향 백과사전 💌

React + Vite + Express + SQLite로 만든 한국어 모바일 설문 웹사이트입니다. Node.js 22.13 이상(현재 검증: Node 24)이 필요합니다.

## 실행

```sh
npm ci
npm run dev
```

기본 포트는 3000입니다. 개발 서버도 Express를 통해 접속하며 API와 화면이 같은 출처에서 동작합니다.

```sh
npm test
npm run build
npm start
```

## 사용법

1. 닉네임으로 참여하고 5개 카테고리의 40문항에 답합니다. 모든 문항은 선택 사항이며 중간 저장 또는 다음 버튼으로 DB에 저장합니다. 입력만 하고 페이지를 떠나면 미저장 답변은 사라집니다.
2. 내 노트 관리에서 친구 초대 링크를 복사해 전달합니다. 최초 접속 시 임의 그룹이 생성되고, 초대 링크로 접속한 친구는 같은 그룹에 참여합니다.
3. 각 참여자가 공유 동의를 저장해야 서로 프로필과 선물 요약을 볼 수 있습니다. 공유 동의는 모든 답변(알레르기 포함)에 적용됩니다. 해제하면 이후 API 조회에서 즉시 제외되지만 이미 본 내용을 회수할 수는 없습니다.
4. 개인 복구 코드는 수정 권한을 가진 비밀번호와 같습니다. 안전하게 별도로 보관하고 다른 사람에게 공유하지 마세요. 같은 브라우저는 localStorage의 코드를 사용하며 다른 기기는 시작 화면의 복구 기능을 사용합니다. 계정이나 이메일 복구 기능은 없습니다.
5. 내 노트 관리에서 답변을 영구 삭제할 수 있습니다.

## DB 및 접근 제어

`server/app.js`에서 시작 시 테이블과 인덱스를 생성합니다. 기본 파일은 `data/survey.sqlite`이며 SQLite WAL 모드를 사용합니다.

- `profiles`: `id`(PK), `token_hash`(고유 SHA-256), `room`(초대 그룹), `nickname`, `sharing`(기본 0), `answers`(문항 ID를 키로 한 JSON), `updated_at`.
- API: `POST /api/join`, `GET/PUT/DELETE /api/me`, `GET /api/friends`, `GET /api/health`.
- 수정 및 친구 조회는 256비트 복구 코드를 Bearer 인증으로 사용합니다. 서버는 원문 코드를 저장하지 않습니다.
- 친구 조회는 요청자 동의와 대상 동의, 같은 그룹 조건을 서버에서 모두 검사합니다. 닉네임만으로 타인의 답변을 불러올 수 없습니다.
- 초대 링크는 그룹 입장 권한이므로 신뢰하는 친구에게만 보내세요. 사용자별 초대 승인이나 실명 확인은 지원하지 않습니다.

## 배포 및 URL 공유

지속 디스크를 지원하는 Node 서버 또는 Render Web Service 같은 서비스에 배포하세요. 정적 호스팅만으로는 SQLite API를 실행할 수 없습니다.

- Build command: `npm ci && npm run build`
- Start command: `npm start`
- Runtime: Node 24
- `PORT`: 호스팅 업체가 지정한 포트를 사용합니다(기본 3000).
- `DB_PATH`: 지속 디스크 경로(예: `/var/data/survey.sqlite`). 해당 디렉터리에 쓰기 권한이 필요합니다.
- 단일 서버 인스턴스로 운영하세요. SQLite 파일을 여러 독립 인스턴스에 분산하면 답변이 달라집니다.
- HTTPS를 켠 후 발급받은 실제 도메인에서 초대 링크를 복사합니다. 데이터 디스크와 WAL을 포함해 SQLite에 적합한 백업을 설정하세요. 재배포 시 임시 파일시스템은 초기화될 수 있습니다.

배포 계정, 결제 및 도메인은 사용자가 준비해야 합니다. 이 저장소에는 임의의 계정이나 인증 정보가 포함되어 있지 않습니다. 공개 대규모 서비스로 확대할 때는 요청 제한, 계정 기반 복구 및 운영 모니터링을 추가하세요. 외부 폰트를 불러올 수 없어도 기본 시스템 폰트로 동작합니다.
